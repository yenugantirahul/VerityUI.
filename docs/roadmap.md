# Delivery roadmap

Complete gates in sequence. A failed criterion requires diagnosis and a rerun before dependent implementation begins. Milestone evidence is recorded in `test-results.md`. External staging, private repositories, production traffic and paid services require explicit owner authorization.

| Phase                    | Implementation backlog and prerequisites                                                                                                                                           | Gate and acceptance evidence                                                                                                                                 |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0 · Toolchain            | Review architecture. Initialize Git and npm. Add build, static checks, loopback health service, smoke tests, environment conventions and CI.                                       | Fresh `npm ci`, formatting, lint, type-check, build, tests and a live HTTP health check. Verify README commands.                                             |
| 1 · Capture              | Build the analytics fixture, profile types, screenshot engine, time and readiness controls, masking, storage-state handling and fixtures. Pin Playwright package and worker image. | Real browser tests for byte stability, device scale, viewport dimensions, authenticated fixtures, component captures, request isolation, errors and cleanup. |
| 2 · Comparison           | Validate PNGs, compare normalized pixels, render diff/heatmap/overlay, localize changed regions and expose statuses. Evaluate geometry checks.                                     | Seeded browser cases for color, missing, shift, overflow, clipping, typography, cosmetic tolerance and identity. Record time and memory.                     |
| 3 · Baselines            | Versioned SQL schema, tenant-scoped immutable artifact store, identity, compare-and-swap approval, rejection, rollback and audit.                                                  | Real Postgres and artifact tests for concurrent approvals, access, corruption, immutability, version history and recoverable I/O.                            |
| 4 · Execution API        | Versioned validated contracts, projects, suite revisions, persisted jobs, leases, cancellation, quotas, retries and cursor listing.                                                | Run creation through evidence retrieval with integration failure injection for crashes, DB, uploads, lease expiry, idempotency and partial results.          |
| 5 · Review UI            | Same-origin React/Vite frontend. Implement organization/project navigation, run history, image comparison controls and approval.                                                   | Browser E2E proves login, run workflow, image inspection, review, authorization and keyboard/mobile behavior.                                                |
| 6 · Evidence analysis    | Explain regions with rules, collect feedback, label dataset and introduce model adapter if evaluation supports it.                                                                 | Document paired quality, localization, latency, resource usage and faithfulness metrics. Preserve critical findings and test inference failure.              |
| 7 · Analytics assertions | KPI and numerics, chart geometry, labels, overflow, filters, readiness and fixture data.                                                                                           | Assert every seeded defect and verify fixture-driven live-data changes remain stable.                                                                        |
| 8 · Developer delivery   | CLI, versioned config, commit associations, workflow and artifact policy, PR review integration.                                                                                   | Real sample PR blocks on seeded defect, exposes evidence and updates an authorized decision. Local workflow validation precedes authorized GitHub use.       |
| 9 · Hosted security      | Tenant security, credentials, network egress, sandbox, resource and retention policies, signed request handling.                                                                   | Tenant and role boundaries, isolated egress, private artifacts, replay handling, malformed input and bounded-resource checks.                                |
| 10 · Operations          | OpenTelemetry, health and alerting, load harness, recovery drills and backup procedures.                                                                                           | Record load latency and resources, failure/restart recovery, and real backup restoration.                                                                    |
| 11 · Release             | Staging and production topology, migrations, infrastructure config and rollback.                                                                                                   | Authorized staging deploy, end-to-end smoke, restore, rollback, security and operational evidence.                                                           |
