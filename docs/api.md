# Local execution API

Use `http://127.0.0.1:4310/api/v1` with `Authorization: Bearer <DELTAFRAME_API_TOKEN>`. The loopback configuration bootstraps one local workspace and administrator. Role checks still run inside database-backed project and review methods. Runtime configuration enables the API when `DATABASE_URL` is set. `/healthz` remains a public liveness endpoint.

| Method and route                                                      | Input and outcome                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /projects`                                                       | List local projects.                                                                                                                                                                                                                                                                              |
| `POST /projects`                                                      | `{"name":"Commerce"}` creates a project and returns 201.                                                                                                                                                                                                                                          |
| `GET /projects/{projectId}/suite`                                     | Latest immutable suite revision or `null`.                                                                                                                                                                                                                                                        |
| `PUT /projects/{projectId}/suite`                                     | `{"checkpoints":[{"key":"desktop","width":1200,"height":800}]}` creates a suite revision. Each checkpoint can include a `selector` and `masks` array.                                                                                                                                             |
| `POST /projects/{projectId}/runs`                                     | `{"suiteId":"…","variant":"original"}` with `Idempotency-Key`. Returns 202 and a persisted run ID. Variant defaults to `original`. Send `color`, `missing`, `shift`, `overflow`, `clipped`, `typography`, or `cosmetic` to exercise fixture changes. An optional `commitSha` associates a commit. |
| `GET /projects/{projectId}/runs?limit=20&before={runId}`              | List run history. Use the last run ID as the next cursor.                                                                                                                                                                                                                                         |
| `GET /projects/{projectId}/runs/{runId}`                              | Job execution states, attempts, comparison evidence and the specific baseline version compared.                                                                                                                                                                                                   |
| `POST /projects/{projectId}/runs/{runId}/cancel`                      | Cancel queued and leased jobs. Completed checkpoints remain available.                                                                                                                                                                                                                            |
| `GET /projects/{projectId}/runs/{runId}/jobs/{jobId}/evidence/{kind}` | Private PNG download. The `kind` is `current`, `baseline`, `diff`, `heatmap`, or `overlay`.                                                                                                                                                                                                       |
| `POST /projects/{projectId}/runs/{runId}/jobs/{jobId}/candidate`      | Create or retrieve the candidate for a completed capture. A stale baseline yields 409.                                                                                                                                                                                                            |
| `POST /projects/{projectId}/baselines/{versionId}/review`             | `{"action":"approve"}` or `{"action":"reject"}`. For rollback, send `{"action":"rollback","expectedActive":"…"}` with the currently observed version ID.                                                                                                                                          |

To try the full flow, create a project and suite, submit the original fixture, and poll run detail until its job is `completed`. Create and approve the candidate, then submit the `color` variant with a new idempotency key. Its comparison should be `changed` and expose the diff. A repeated key with the same input returns the original run. A repeated key with different input returns 409.

Each worker processes one job at a time. Its 45-second lease has a unique claim ID. A retry or reassignment invalidates old completions. Transient failures requeue up to three attempts with bounded backoff. Cancellation revokes the lease immediately, with browser cleanup following the normal capture deadline. A failed job has a stable failure code and no comparison result. Local per-organization queue capacity is 48 jobs.

The dashboard signs in with `POST /session` and `{"token":"…"}`. The response sets an HttpOnly, SameSite Strict cookie. `GET /session` returns current and accessible workspaces. `PATCH /session` with `{"workspaceId":"…"}` selects an authorized workspace for future browser requests, and `DELETE /session` signs out. Bearer requests retain the configured operator's default workspace. `GET` on a checkpoint's `candidate` route provides its recorded review decision.
