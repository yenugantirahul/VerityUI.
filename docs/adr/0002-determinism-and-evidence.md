# ADR 0002 · Preserve deterministic evidence and baseline history

Status: Accepted

Use exact browser/environment identity, immutable content-addressed screenshots, and compare-and-swap baseline pointers. Each comparison retains its specific baseline version. A pointer rollback appends an audit event and retains historical artifacts. Pixel and analytics assertions determine deterministic status. Analysis can add findings and explanations without changing result or review state. Structural metrics and models need paired fixture evidence before adoption.
